# Lab de Segurança - OWASP Top 10

Este repositório contém um laboratório prático para estudo, demonstração e testes de vulnerabilidades de segurança em aplicações web, baseado nas diretrizes do **OWASP Top 10**.

## 📌 Sobre o Projeto

O objetivo deste projeto é fornecer um ambiente controlado para identificar, explorar e corrigir falhas de segurança comuns em desenvolvimento de software, promovendo boas práticas de programação segura e conscientização em cibersegurança.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem Principal:** Python (v3.14+)
* **Gerenciamento de Ambientes:** Virtualenv (`.venv`)
* **Testes e Validação:** `pytest`
* **Controle de Versão:** Git
